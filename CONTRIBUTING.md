# Contributing

Open an issue before changing the supported artifact tuple, 35-ID allowlist,
260-path resource closure, 3×3 giant behavior, animation policy, or stock
boundary. Compatibility is an exact profile, never a version range.

Contributions must be compatible with this project's MIT license. Only the
identified MIT BlueMap Chisel Add-on lineage may be adapted without a new
provenance decision. Do not copy Factory Blocks, Athena, CTM, Chisel content,
or Minecraft code or assets. Third-party artifact inputs remain local.

Preserve route-wide fail-closed activation, first-resource-wins schema
validation, collision-safe IDs, and atomic per-block fallback. Record runtime,
browser, owner-review, and publication claims only after the exact
corresponding gate actually ran.
